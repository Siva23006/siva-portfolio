# Siva — Portfolio

Personal portfolio website of Siva B, AI & Data Science undergraduate and founder of Nexi Net.

**Live:** https://siva-b.vercel.app

## Tech stack

- Next.js 15 (App Router) and React 19
- TypeScript
- Tailwind CSS
- Framer Motion and GSAP for animation
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build for production

```bash
npm run build
npm start
```

## Deploy

Import the repo on [Vercel](https://vercel.com) and click Deploy. Every push to `main` redeploys automatically.

## Project structure

- `app/` — layout, page and page template
- `components/` — UI components and page sections
- `data/site.ts` — name, links, contact details and content
- `public/` — images and resume PDF
- `styles/` — global CSS
